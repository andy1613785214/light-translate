# 安装与更新

## 下载和安装

1. 打开[最新 Release](https://github.com/andy1613785214/light-translate/releases/latest)，下载 `LightTranslate-版本-arm64.dmg`。
2. 打开 DMG，将“轻译”拖到 Applications。替换旧版前先从菜单栏退出旧应用。
3. 在应用程序目录启动轻译；现有服务、快捷键和 Keychain 密钥会继续使用。
4. 首次取词需要在系统辅助功能设置中授权安装后的应用。

ZIP 适合手动解压安装。不要直接长期在 DMG 内运行，磁盘映像为只读，无法完成应用内更新。

## 应用内更新

菜单栏或浮窗“…”中选择“检查更新…”。Sparkle 会显示新版本，用户确认后下载安装并重启。启用自动检查，不自动安装。更新信息和 ZIP 均以 Ed25519 签名；更新入口不会读取翻译 API 密钥，也不上传正文。

## 当前签名限制

维护者暂时没有 Apple Developer ID 证书。此 Release 为本地 ad-hoc 签名，未进行苹果公证，不能承诺从互联网下载后无安全提示启动。请只使用此仓库的公开发布文件；不提供关闭系统安全机制的安装脚本。

更新后若系统保留的辅助功能授权不再有效，在系统设置中移除旧条目，重新添加应用程序目录的当前轻译，并重启。未来接入稳定 Developer ID 签名后会改善分发与权限连续性。

## 完整性

Release 附带 `SHA256SUMS.txt`，可在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt`。SHA-256 用于完整性核对；应用内更新另外使用内置公钥验证签名。
