原生 macOS 菜单栏中英翻译工具，支持 Apple Silicon、macOS 14+。

- macOS 26 原生 Liquid Glass；旧版系统磨砂兼容，精简设置页。
- 等待时右上角仅显示“正在翻译”，返回后展开译文。
- 句子模式默认折叠原文与词汇；单个英文词直接展开详细解释。
- DMG 拖拽安装、ZIP 分发，以及验证更新包和更新信息签名的应用内更新。
- API 密钥仅保存在本机 Keychain，个人配置不包含在发布文件中。

安装：打开 DMG，将轻译拖入 Applications，再启动应用并配置 API 与辅助功能权限。

**签名状态：本地 ad-hoc，尚未 Developer ID 签名或苹果公证。macOS 可能阻止首次运行网络下载的应用。** 更新后的辅助功能权限可能需要重新关联当前应用。
